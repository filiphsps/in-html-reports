Security finding

One concrete credential-handling issue needs correction before merge. It is a conditional exposure in the workflow design; this review did not find evidence that the fork has already exploited it.

HIGH · FIX BEFORE MERGE

Recovery tag code inherits a write-scoped GitHub token

This diff turns recovery into a reusable publish job, grants it contents: write, and sets GH_TOKEN at job scope. It checks out the selected tag, runs pnpm install, then resolves plugin metadata by dynamically importing the tag's configured info module. Tag and commit verification happens afterward. If release assets are missing, it also runs pnpm run build from that source. All those source-controlled commands inherit the token. In the base revision, recovery scoped GH_TOKEN to individual GitHub API steps.

[publish-plugin-release.yml:35–40] write permission + job-wide token
[publish-plugin-release.yml:53–75] selected tag checkout, install, and plugin resolution
[resolve-plugin-release.mjs:42] loads the plugin info module
[plugin-info.mjs:22–25] dynamically imports that module
[publish-plugin-release.yml:77–90] tag/commit validation occurs after source code runs
[publish-plugin-release.yml:147–152] released source build
[recover-plugin-release.yml:25–41] default-branch dispatch passes the requested tag and inherited secrets
[base recover-plugin-release.yml:67–71] token was step-scoped

Consequence: if an authorized workflow dispatcher selects a malicious or compromised tag, its install lifecycle or plugin info module can read and transmit the token before tag verification. The later build also inherits it. The token can write repository contents and release assets. Requiring dispatch from the default branch does not make the selected tag's code trusted.

Fix: remove GH_TOKEN from the job environment. Set it only on trusted steps that call gh api or upload/download release assets; run tag checkout, dependency installation, metadata import, and build without that credential. Validate the tag and commit before any source-controlled scripts execute.
